These are recommendations, not requirements. Nothing here is enforced and no
check will score a repository against it. Use what helps.

## Development plugins and utilities

* Query Monitor
* FakerPress
* Regenerate Thumbnails
* Transients Manager
* WP Crontrol
* User Switching

## Local development environments

* `wordpress-develop` Docker environment (great for core contribution)
* Lando (Docker-based CLI with WordPress recipe)
* LocalWP (cross-platform GUI bundled with WP-CLI, Adminer, Xdebug support and
  easy MySQL client access)
